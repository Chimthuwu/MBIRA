## 5. Key facts worth keeping

- Param paths the DSP accepts are the allowlist in `src/native/webview_ui.h`
  (`dspAccepts`); `setParam` in `src/dsp/index.js` throws on anything else.
- Mod strip params: `mod.<geometry|material|decay|pluck|noise|hardness>.<vel|key|rnd>`
  plus `mod.<geometry|material|decay>.lfo` (LFO is not offered on strike-time
  targets: pluck/noise/hardness).
- DSP modulation is `base + Σ(depth × source)`, clamped 0..1. vel/key/rnd are
  latched in `noteOn()` (`st.src`); the LFO is a signal, so geometry’s ratio
  morph is built as nodes and material/decay’s tau is a signal into `pole`.
  The signal path strikes with a unit impulse (`env = p*env + edge`) — the
  normalised `(1-p)` form pumps the level when `p` moves.
- Preset snapshot shape: `{ v: 1, params: { "<param path>": value } }`, 32 keys.
  Recall = a batch of `param.set` (ramped, **not** block-atomic — §5.4 work).
- UI controls expose `{get,set}` maps from `mountFaders/mountKnobs/mountModStrips`;
  `lfo.rate` is added by hand in `ui/js/main.js`. Presets depend on those maps.
- Layout rule of thumb: keep the canvas out of intrinsic-size layout decisions
  (`flex-basis: 0`), and remember `.view{grid-auto-rows:max-content}`.
